# 服务守护与日常操作卡

> 两个服务：**LM Studio**（模型后端，端口 1234）+ **Open-LLM-VTuber**（交互核心，端口 12393）
> 看门狗：`C:\work\olv-config\watchdog.ps1`，日志 `C:\work\olv-config\watchdog.log`

---

## 它现在是怎么工作的

```
登录 Windows
   └─ 启动文件夹里的 OpenLLMVTuber-看门狗.vbs（静默、无窗口）
        └─ 看门狗 watchdog.ps1（常驻，每 30 秒检查一次）
             ├─ 1234  不通 → 先试 `lms server start`；主程序没了就重启 LM Studio
             └─ 12393 不通 → 清残留进程，重新拉起 Open-LLM-VTuber
```

**自启位置**（用户级，不需要管理员）：
```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\OpenLLMVTuber-看门狗.vbs
```

**你要做的：什么都不用做。** 开机登录后约一分钟内两个服务会自动就绪，然后直接用浏览器打开 <http://localhost:12393>。

## 常用操作

| 想干什么 | 怎么做 |
|---|---|
| **正常使用** | 开机什么都不用管，浏览器开 <http://localhost:12393> |
| **确认服务状态** | 双击 `C:\work\olv-config\启动.bat`（会显示两个服务是否就绪并打开界面） |
| **看运行日志** | 打开 `C:\work\olv-config\watchdog.log` |
| **停止守护** | 双击 `C:\work\olv-config\停止看门狗.bat` |

## 改脚本时的一个大坑（务必注意）

`watchdog.ps1` 里有中文，**必须保存为「UTF-8 带 BOM」**。

原因：Windows PowerShell 5.1（本机版本）在 `.ps1` **没有 BOM** 时会按 **ANSI/GBK** 解析文件。中文注释的字节会被误解，导致语法解析直接崩掉，报出一些完全看不懂的错误，例如：

```
表达式或语句中包含意外的标记"}"
字符串缺少终止符: '。
```

这些错误信息**指向的行号往往是错的**（真正原因在文件头部的编码），很容易查半天。

**修改后用这条命令检查（纯 ASCII，安全）：**

```powershell
$p='C:\work\olv-config\watchdog.ps1'
[System.IO.File]::WriteAllText($p,
  [System.IO.File]::ReadAllText($p,(New-Object System.Text.UTF8Encoding($false))),
  (New-Object System.Text.UTF8Encoding($true)))
$e=$null; [void][System.Management.Automation.Language.Parser]::ParseFile($p,[ref]$null,[ref]$e)
if($e.Count){$e|%{"ERR line $($_.Extent.StartLineNumber): $($_.Message)"}}else{"SYNTAX OK"}
```

## 已知限制

1. **计划任务不可用**：这台机器上 `schtasks` 和 Task Scheduler COM 接口都访问不了
   （报 `Access is denied` / 找不到任务文件夹），所以自启改用**启动文件夹**实现。
   效果等价于「登录时启动」，只是不能在 GUI 里手动调整触发条件。

2. **LM Studio 自身崩溃尚未根因定位**：调试期间它崩过两次，日志特征一致：
   ```
   [error] Error: Local inference is changing ownership. Please try again shortly.
   ```
   这是 LM Studio 自己的内部错误（推理所有权切换），**与我们的配置无关**
   （`max_tokens`、上下文长度都验证过是正常的）。好消息是现在有看门狗兜着，
   崩了会自动重启。

3. **开机自启需要登录**：用的是登录触发，不是开机触发。如果你希望**不登录也跑**，
   那必须用计划任务或 Windows 服务 —— 都需要管理员权限，需要你自己以管理员身份操作。

## 待你决定：换模型

你提到打算用 **Qwen3.6-35B-A3B-Uncensored-HauhauCS-Aggressive**。目前还没安装，等你装好后只要改一处：

`C:\work\Open-LLM-VTuber\conf.yaml` 里：
```yaml
      lmstudio_llm:
        model: '改成新模型在 /v1/models 里的 id'
        max_tokens: 1024     # 若新模型也有思考过程，这一项要保留
```

查新模型 id 的方法：
```powershell
(Invoke-RestMethod 'http://127.0.0.1:1234/v1/models').data.id
```

⚠️ 两个提醒：
- **注意量化格式**：如果那个模型你下到的是 **MLX** 格式，LM Studio 在 Windows 上用不了，
  需要 **GGUF** 版本。
- 换完模型后，如果角色又"不出声"了，八成还是**思考 token 吃光预算**那个问题 ——
  把 `max_tokens` 调大（如 2048）试试。
